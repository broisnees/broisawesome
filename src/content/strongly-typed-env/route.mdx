I keep environment variables typed and validated in React Router v7 and Remix
with a small Zod setup. It starts with an `env.common.ts` file in a `misc` or
`utils` folder.

Define the public schema with Zod:

```tsx
// env.common.ts

const publicEnvSchema = z.object({
  GOOGLE_MAPS_API_KEY: z.string(),
  STRIPE_PUBLIC_KEY: z.string(),
});
```

Next comes `makeTypedEnv`. It takes a schema and returns a function that parses
the raw environment variables and returns them strongly typed.

```tsx
// env.common.ts

function makeTypedEnv<T>(schema: { parse: (data: unknown) => T }) {
  return (args: Record<string, unknown>) => camelKeys(schema.parse(args));
}
```

## A type-safe environment helper

Then `getPublicEnvExpose`, which parses `process.env` on the server, and
`getPublicEnvFrom`, the parser for the public schema:

```tsx
// env.common.ts

export function getPublicEnvExpose() {
  if (typeof window == 'undefined') {
    return getPublicEnvFrom(process.env);
  }
}

const getPublicEnvFrom = makeTypedEnv(publicEnvSchema);
```

`getPublicEnv` returns the typed public variables on either side. On the server
it parses `process.env`. In the browser it parses `window.PUBLIC_ENV`, and throws
if those were never exposed. The file also exports the `PublicEnv` and
`PrivateEnv` types.

```tsx
// env.common.ts

export type PublicEnv = ReturnType<typeof getPublicEnvFrom>;
export type PrivateEnv = ReturnType<typeof getPrivateEnvFrom>;

function getPublicEnv() {
  if (typeof window == 'undefined') {
    return getPublicEnvFrom(process.env);
  }

  if (!window.PUBLIC_ENV) {
    throw new Error('PUBLIC_ENV is not defined, Not exposed!');
  }

  return getPublicEnvFrom(window.PUBLIC_ENV);
}

export { publicEnvSchema, makeTypedEnv, getPublicEnv };
```

## Exposing public variables to the browser

Create `utils.tsx` with a `PublicEnv` component. It takes the public variables
as props and writes them to `window.PUBLIC_ENV` with an inline script. The
`declare global` block types `window.PUBLIC_ENV`.

```tsx
// utils.tsx

type Props = ReturnType<typeof getPublicEnvExpose>;

function PublicEnv(props: Props) {
  return (
    <script
      id="public-env"
      dangerouslySetInnerHTML={{
        __html: `window.PUBLIC_ENV = ${JSON.stringify(props)};`,
      }}
    />
  );
}

export { PublicEnv };

declare global {
  interface Window {
    PUBLIC_ENV: Props;
  }
}
```

Finally, return `publicEnv` from the root loader in `root.tsx` and render
`PublicEnv` in the document:

```tsx
// root.tsx
export async function loader({ request }: Route.LoaderArgs) {
  return data({
    requestInfo: {
      hints: getHints(request),
      path: new URL(request.url).pathname,
      userPrefs: {
        theme: getTheme(request),
      },
    },
    publicEnv: getPublicEnv(),
  });
}

function Document({
  children,
  theme = 'light',
  loaderData,
}: {
  children: React.ReactNode;
  loaderData: Route.ComponentProps['loaderData'];
  theme?: Theme;
}) {
  return (
    <html lang="en" className={clsx(theme)} data-theme={theme}>
      <head>
        <ClientHintCheck nonce={new Date().toString()} />
        <meta charSet="utf-8" />
        <meta
          name="color-scheme"
          content={theme === 'light' ? 'light' : 'dark'}
        />
        <meta name="MobileOptimized" content="320" />
        <meta name="pagename" content="Nischal Dahal" />
        <meta name="mobile-web-app-capable" content="yes" />
        <Meta />
        <Links />
      </head>
      <body className="">
        <Layout>
          <Navbar theme={theme} />
          {children}
        </Layout>
        <ScrollRestoration
          getKey={(location) => {
            return location.pathname;
          }}
        />
        <Scripts />
        <PublicEnv {...loaderData.publicEnv} />
      </body>
    </html>
  );
}
```

## Using ArkType instead

The schema doesn't have to be Zod. The same idea works with ArkType:

```tsx
// Define the environment schema using ArkType.

const envArkSchema = type({
  MODE: ['"development"|"test"|"production"', '=', 'development'],
});

// // Create the environment parser for ArkType.
const getArkEnv = makeTypedEnvironment((d) => envArkSchema.assert(d));
```
